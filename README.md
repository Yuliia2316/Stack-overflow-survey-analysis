# Stack Overflow Developer Survey Analysis 📊

## Project Overview
This project provides a comprehensive analysis of the Stack Overflow Annual Developer Survey. The main goal is to uncover insights into the tech industry, specifically focusing on developer compensation, geographic trends, and the most popular programming languages.

## Key Goals
* **Data Cleaning:** Processing and filtering survey responses for analysis using Pandas.
* **Exploratory Data Analysis (EDA):** Identifying correlations between professional experience and salary.
* **Visualization:** Creating visual representations of technology trends and market demands.

## Tech Stack
* **Language:** Python
* **Library:** Pandas
* **Environment:** Jupyter Notebook (Salary_Analysis.ipynb)

## How to Use
1. Clone this repository.
2. Ensure you have the `survey_results_public.csv` file in the project directory.
3. Run the `Salary_Analysis.ipynb` notebook.
